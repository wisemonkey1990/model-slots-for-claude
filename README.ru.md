# Model Slots for Claude

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md)

Расширение Claude Desktop (`.mcpb`), которое оставляет официальный Claude вашей основной моделью и позволяет вызывать сторонние модели — DeepSeek, GLM, GPT, Gemini и другие — через **локальный шлюз, совместимый с OpenAI** (по умолчанию: [Magpie](https://github.com/yetone/magpie) по адресу `http://127.0.0.1:3425/v1`). Это похоже на добавление нескольких дополнительных «слотов моделей» в Claude; расширение также помогает экономить токены Claude.

> **Неофициальное расширение.** Не связано с Anthropic или проектом Magpie, не одобрено и не поддерживается ими. «Claude» — товарный знак Anthropic.

## Что вы получаете

| Возможность | Как это работает |
|---|---|
| **Слоты моделей `@alias`** | Начните сообщение с `@ds`, `@gpt`, `@glm`… — и Claude передаст его этой модели. История нескольких ходов сохраняется для каждого разговора Claude, записывается на диск и сохраняется после перезапуска. `@ds @gpt …` отправляет запрос нескольким моделям одновременно. |
| **Маршрутизация задач** | Для каждой из задач `general / code / reasoning / writing / translate / quick` задаётся список моделей; при сбое выполняется попытка с очередной моделью, а только что отказавшие модели перемещаются в конец списка на 10 минут. |
| **Сравнение нескольких моделей** | Один и тот же вопрос отправляется параллельно 2–5 моделям; даже при частичных сбоях успешные ответы всё равно возвращаются. |
| **Файловый режим (экономия токенов)** | Расширение читает локальные текстовые файлы и записывает результаты обратно в файлы, поэтому длинные документы не проходят через разговор. Длинные документы разбиваются на части (по 3 параллельно), а неудачные части можно обработать повторно. |
| **Получение ответов** | Получайте полный текст предыдущего ответа, включая длинные ответы, сохранённые в файлах, чтобы Claude мог их проверить. |
| **Изменение настроек на лету** | Добавляйте и удаляйте псевдонимы, изменяйте маршруты или режим отображения прямо в чате (`magpie_config`) — перезапуск не требуется. |
| **Статистика использования** | `magpie_status` показывает количество вызовов, сбоев, среднюю задержку и число токенов для каждой модели за последние 7 дней. |
| **Горячая перезагрузка** | Основной код находится в `Documents/Magpie Chat/core/core.mjs`; изменения вступают в силу при следующем вызове без переустановки. Если новый код не загрузится, продолжит работать последняя рабочая версия. |

Инструменты: `magpie_chat`, `magpie_ask`, `magpie_compare`, `magpie_recall`, `magpie_config`, `magpie_list_models`, `magpie_status`. (Префикс `magpie_` используется по историческим причинам; подойдёт любой шлюз, совместимый с OpenAI.)

## Требования

- Claude Desktop (Windows или macOS) с включёнными расширениями. Расширение работает на встроенном в Claude Desktop Node.js.
- Локальный шлюз, совместимый с OpenAI, который предоставляет `/v1/chat/completions` и `/v1/models`, например Magpie.
- Использование сторонних моделей оплачивается теми провайдерами, которых использует ваш шлюз, а не вашим тарифом Claude.

## Установка

1. Скачайте последнюю версию `magpie-chat-<version>.mcpb` из папки [`dist/`](dist/) (нажмите на файл, затем выберите **Download raw file**) или из раздела [Releases](../../releases), если он доступен.
2. Дважды щёлкните по файлу (или перетащите его в Claude Desktop → Settings → Extensions).
3. Проверьте настройки: модель по умолчанию, модели для отдельных задач, псевдонимы (например, `ds=auto/deepseek-v4.1-flash, gpt=auto/gpt-6.1-sol`) и **разрешённые папки** для файлового режима. Идентификаторы моделей по умолчанию соответствуют именованию Magpie — замените их на идентификаторы, которые отображаются в вашем шлюзе.
4. Полностью закройте Claude из системного трея и снова запустите его.
5. В **новом** разговоре попросите Claude запустить `magpie_status`, затем попробуйте `@ds hello`.

## Рекомендуется: дополнительный навык

`skill/magpie-collab/SKILL.md` учит Claude правильно использовать инструменты: передавать сообщения `@alias` без изменений, передавать вводные через `context`, соблюдать инструкции по отображению, использовать команды быстрого доступа (`#审` review, `#译` translate, `#比` compare, `#稿` draft→review→finalize), автоматически запускать перекрёстную проверку в нужных случаях и считать вывод сторонних моделей ненадёжным. Добавьте его в Claude как навык или вставьте в инструкции проекта.

## Проверка реальной экономии токенов

- Если ответ сторонней модели отображается в чате, Claude должен вывести его повторно — это стоит примерно столько же, сколько самостоятельный ответ Claude.
- Перекрёстная проверка **увеличивает** расход Claude; она повышает качество, но не экономит токены.
- Экономия достигается главным образом за счёт **файлового режима**: длинные входные и выходные данные остаются на диске.
- Длинные ответы `@alias` записываются в файлы и автоматически открываются (порог можно настроить).

## Безопасность и конфиденциальность

- Файловый режим читает и записывает данные только внутри разрешённых вами папок. Пути разрешаются через `realpath` перед проверкой, что блокирует выход через `..` и симлинки; двоичные файлы и файлы размером более 5 МБ отклоняются; существующие файлы никогда не перезаписываются без вашего согласия.
- Вывод сторонних моделей считается ненадёжными данными; навык указывает Claude никогда не выполнять инструкции, найденные в этом выводе.
- **Горячая перезагрузка выполняет `core/core.mjs`.** Любой объект, который может записывать данные в эту папку, способен запускать код через это расширение. Не предоставляйте эту папку ненадёжным пользователям и не синхронизируйте её с ними.
- Ваш шлюз может передавать данные через сторонние ретрансляторы. Обдумайте последствия перед отправкой неопубликованных или конфиденциальных материалов.
- Данные остаются локальными: ответы, сеансы, журналы и настройки хранятся в `Documents/Magpie Chat` (подпапка `.state`).

## Известные ограничения

- Системные сообщения расширения и дополнительный навык написаны на упрощённом китайском; Claude всё равно будет отвечать вам на вашем языке.
- Выбор моделей в Claude Desktop не может отображать сторонние модели, а поле ввода не поддерживает автодополнение `@`. Вместо этого расширение работает через инструменты и навык.
- Ответы нельзя передавать в чат потоково.
- Только для Desktop (локальный шлюз должен находиться на том же компьютере).
- Описания инструментов кэшируются для каждого разговора — после обновлений, добавляющих инструменты, откройте новый разговор.

## Разработка

```bash
node tests/selftest.mjs          # 27 checks against a mock gateway, in a temp dir
npm i -g @anthropic-ai/mcpb
mcpb validate manifest.json
mcpb pack . magpie-chat.mcpb
```

`server/index.mjs` — это загрузчик без дополнительной логики (MCP через stdio и горячая перезагрузка); `server/core.mjs` содержит все возможности. Зависимостей нет, требуется Node ≥ 18.
